## Project Context

- **Project:** gh-aw (GitHub Agentic Workflows)
- **Universe:** The Usual Suspects
- **Created:** 2026-08-17
- **What it is:** A Go-based `gh` CLI extension (~2850 Go files) that compiles Markdown + YAML frontmatter agentic workflows into standard GitHub Actions workflows, with a large linters package, custom GitHub Actions, extensive Starlight docs, and skill-based Copilot conventions.
